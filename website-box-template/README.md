# Website-in-a-box Template

Reusable static website starter for local businesses in Cyprus.

## Customize a customer
Edit only `config.js` for the normal customer setup:
- business name and tagline
- phone / WhatsApp / email
- address and Google Maps link
- opening hours
- services and prices
- booking URL

The shared layout lives in `index.html`, styling in `styles.css`, and config rendering in `script.js`.

## Netlify
This folder is static and can be deployed directly. If this template later moves to its own repository, set the Netlify publish directory to the repository root. While it lives inside this repository, use `website-box-template` as the publish directory.
